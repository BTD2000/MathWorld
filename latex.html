LaTeX Guide

LaTeX is a typesetting system widely used to write mathematical expressions, equations, and scientific documents. MathWorld uses LaTeX to display mathematical notation clearly.

Getting Started

You can write mathematical expressions using dollar signs or square brackets.

Inline Mathematics

Use $...$ or \(...\) to write mathematical expressions within a line of text.

Example

The quadratic formula is $x=\frac{-b\pm\sqrt{b^2-4ac}}{2a}$.

The quadratic formula is \(x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}\).

Display Mathematics

Use $$...$$ or \[...\] to display mathematical expressions on a separate line. This is especially useful for long equations and derivations.

Example


\[
    \sum_{k=1}^{n}k=\frac{n(n+1)}{2}
\]
\[ \sum_{k=1}^{n} k = \frac{n(n+1)}{2} \]

Fractions

Use \frac{a}{b} to write a fraction.

Example


\[
    \frac{a+b}{c+d}
\]
\[ \frac{a+b}{c+d} \]

Powers and Subscripts

Use ^ to write powers and _ to write subscripts.

Example


\[
    x^2+x_1+a_{n+1}+x^{n+1}
\]
\[ x^2 + x_1 + a_{n+1} + x^{n+1} \]

Square Roots

Use \sqrt{...} to write square roots. You can also specify the root degree using \sqrt[n]{...}.

Example


\[
    \sqrt{x}+\sqrt[3]{x}+\sqrt{a^2+b^2}
\]
\[ \sqrt{x} + \sqrt[3]{x} + \sqrt{a^2+b^2} \]

Greek Letters

Use a backslash followed by the name of a Greek letter to write it. Capitalize the first letter for uppercase versions.

Example


\[
    \alpha,\ \beta,\ \gamma,\ \delta,\ \theta,\ \lambda,\ \mu,\ \pi,\ \sigma,\ \omega
\]

\[
    \Gamma,\ \Delta,\ \Theta,\ \Lambda,\ \Pi,\ \Sigma,\ \Omega
\]
\[ \alpha,\ \beta,\ \gamma,\ \delta,\ \theta,\ \lambda,\ \mu,\ \pi,\ \sigma,\ \omega \] \[ \Gamma,\ \Delta,\ \Theta,\ \Lambda,\ \Pi,\ \Sigma,\ \Omega \]

Summation and Products

Use \sum for summations and \prod for products. Use _ and ^ to specify the lower and upper limits.

Example


\[
    \sum_{k=1}^{n}k=\frac{n(n+1)}{2}
\]

\[
    \prod_{k=1}^{n}k=n!
\]
\[ \sum_{k=1}^{n} k = \frac{n(n+1)}{2} \] \[ \prod_{k=1}^{n} k = n! \]

Sets and Relations

LaTeX provides commands for common set symbols, logical relations, and mathematical comparisons.

Example


\[
    A\subseteq B,\quad x\in A,\quad y\notin B
\]

\[
    A\cup B,\quad A\cap B,\quad A\setminus B
\]

\[
    a\leq b,\quad x\neq y,\quad a\equiv b\pmod n
\]
\[ A \subseteq B,\quad x \in A,\quad y \notin B \] \[ A \cup B,\quad A \cap B,\quad A \setminus B \] \[ a \leq b,\quad x \neq y,\quad a \equiv b \pmod n \]
