BBCode Guide

BBCode is a lightweight markup language used to format text and organize mathematical solutions on MathWorld. It uses simple tags enclosed in square brackets.

Getting Started

To format text, place an opening tag before the content and a closing tag after it. 

[b]This text is bold.[/b]

Text Formatting

BBCode provides several tags that allow you to change the appearance of your text.

Bold

Use [b] to make text bold.

[b]This text is bold.[/b]
This text is bold.

Italic

Use [i] to make text italic.

[i]This text is italic.[/i]
This text is italic.

Underline

Use [u] to underline text.

[u]This text is underlined.[/u]
This text is underlined.

Strikethrough

Use [s] to draw a line through text.

[s]This text is crossed out.[/s]
This text is crossed out.

Lists

BBCode allows you to create both unordered and ordered lists. Use [*] to start each list item.

Unordered List

Use [list] to create a bulleted list.


[list]
    [*]Algebra
    [*]Geometry
    [*]Combinatorics
    [*]Number Theory
[/list]
  • Algebra
  • Geometry
  • Combinatorics
  • Number Theory

Numbered List

Use [list=1] to create a numbered list.


[list=1]
    [*]First step
    [*]Second step
    [*]Third step
[/list]
  1. First step
  2. Second step
  3. Third step

Lettered Lists

You can use lowercase or uppercase letters as list markers. 


[list=a]
    [*]First item
    [*]Second item
[/list]

[list=a-upper]
    [*]First item
    [*]Second item
[/list]

Lowercase letters:

  1. First item
  2. Second item

Uppercase letters:

  1. First item
  2. Second item

Roman Numeral Lists

Use [list=i] or [list=i-upper] to create lists with Roman numerals. 


[list=i]
    [*]First item
    [*]Second item
[/list]

[list=i-upper]
    [*]First item
    [*]Second item
[/list]

Lowercase Roman numerals:

  1. First item
  2. Second item

Uppercase Roman numerals:

  1. First item
  2. Second item

Links

You can add hyperlinks to your posts using the [url] tag. There are two ways to create a link.

Basic URL

Place the URL between the opening and closing tags. The URL itself will be displayed as the link text. 

[url]https://example.com[/url]
https://example.com

Custom Link Text

You can also specify the text displayed for the link by placing the URL inside the opening tag. 

[url=https://example.com]Visit Example[/url]
Visit Example

Horizontal Lines

Use the [ruler] tag to insert a horizontal line and visually separate different parts of your writing.

Horizontal Separator


First part of the solution.

[ruler]

Second part of the solution.
